# Thư mục chứa nhạc nền cục bộ

Để thay nhạc nền sinh nhật riêng:
1. Copy file nhạc của bạn vào đây.
2. Đổi tên thành: `birthday-music.mp3`
3. Trình duyệt sẽ tự động phát nhạc này offline mà không lo bị chặn bản quyền hay lỗi CORS!
(Nếu không có file mp3, website sẽ tự động dùng bộ tổng hợp âm thanh Web Audio Synthesizer có sẵn).
